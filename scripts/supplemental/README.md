# Supplemental analyses

This folder contains optional extensions that are not part of the numbered
course workflow. Supplemental Python scripts deliberately have descriptive
names without numeric prefixes, so moving an extension here never changes the
order of the main scripts.

- `multiscale_module_movie.py` rebuilds module maps across spatial parcel sizes
  and renders a static overview plus an MP4 or GIF movie.

Run a supplemental script cell by cell after completing the related numbered
analysis. The multiscale movie builds on scripts 05 and 06.
