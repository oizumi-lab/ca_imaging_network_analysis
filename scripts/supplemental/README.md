# Supplemental analyses

This folder contains optional extensions that are not part of the numbered
tutorial workflow. Supplemental notebooks deliberately have descriptive
names without numeric prefixes, so moving an extension here never changes the
order of the main notebooks.

- `multiscale_module_movie.ipynb` rebuilds module maps across spatial parcel sizes
  and renders a static overview plus an MP4 or GIF movie.

Run a supplemental notebook cell by cell after completing the related numbered
analysis. The multiscale movie builds on notebooks 05 and 06.
